# Responsive And Touch

Test desktop, tablet, mobile, and the transitions between them.

- Maintain usable touch targets, readable text, adequate spacing, and visible focused controls.
- Check page and panel overflow, unintended horizontal scrolling, drawer width/closing behavior, and toolbar density.
- Keep the UML canvas usable for pan, zoom, selection, and essential tools; mobile is not desktop compressed into a narrow column.
- Preserve browser zoom. Do not make gesture-only interactions mandatory when an alternate control is feasible.
- Verify long model names, diagnostics, and Inspector property values do not create inaccessible clipping or broken layout.

Review CU-02 responsive history before changing editor breakpoints, canvas mounting, drawers, or fit behavior.
